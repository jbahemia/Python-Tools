ClearLineLocks.py (ClearLineLocks.exe is developed by Teledyne Caris and required)

This tool will clear hips line locks on all .hips folders within the project folder given, and output the results to a text file in the parent folder. User specifies the parent folder at the prompt and then the ClearLineLocks.exe file as well.
--------------------------
csar_band_stats.py (requires Numpy and Python 3.11)

This tool uses the Caris API (path defined near top of code) to directly load the csars in a folder into a Numpy array and calculate statistics exported to a text file for pre-defined bands.
